Aturan & Rumus Otomatis (Transaksi):

  • Pemisahan Non-Member: Baris data POS dengan kolom mbrps == 9999999999 otomatis dipisah ke sheet DATA NON MEMBER.
  • Point Positif & Negatif Magento: Point Positif = IF(Point > 0, Point, 0) dan Point Negatif = IF(Point < 0, Point, 0).
  • Sheet Rekap Bersih: Dibuat otomatis mengambil kolom Transaction No., Point Positif, dan Point Negatif.
  • Point Magento: Diambil dari Rekap Bersih (jika pointrpps > 0 ambil positif, jika tidak ambil negatif). Jika tidak ada diisi "Tidak ditemukan".
  • Status & Keterangan: Status menghasilkan "SAMA" (Keterangan: Point cocok), "TRANSAKSI TIDAK DITEMUKAN" (Keterangan: Tidak ada pada Magento), atau "TIDAK SAMA" (Keterangan: Nilai berbeda).
  • Summary Box: Otomatis ditambahkan di samping tabel sheet DATA MEMBER.

Rekonsiliasi Data Member & Magento Lois

Unggah file Data Member POS dan file Data Member Magento untuk memvalidasi nama, mencocokkan saldo point, mendeteksi duplikat, dan mengunduh laporan 3 sheet.

Aturan & Rumus Otomatis (Member):

  • LAC No (Key): Standarisasi 10 digit (leading zero) pada data Magento dan TRIM(kdmbr) pada data POS.
  • Lookup Data: Mengambil Nama Magento dan Point Magento berdasarkan LAC No (Key).
  • Hasil Nama: Membandingkan Nama POS dan Nama Magento (case-insensitive & trim) $\rightarrow$ SESUAI / TIDAK SESUAI.
  • Hasil Point: Membandingkan poin POS dengan poin Magento (pembulatan 2 desimal) $\rightarrow$ SAMA / TIDAK SAMA.
  • Validasi Ganda: VALID (LAC No & Nama cocok) jika nama sesuai, atau PERLU DICEK MANUAL jika nama berbeda.
  • Keterangan: Data sesuai, Nama berbeda - perlu dicek, Point berbeda, Nama dan Point berbeda - perlu dicek, atau Tidak ditemukan di Magento.
  • Cek Duplikat: Mendeteksi apakah kdmbr muncul lebih dari satu kali $\rightarrow$ DUPLIKAT / TIDAK DUPLIKAT.
